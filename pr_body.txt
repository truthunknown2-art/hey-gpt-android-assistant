## Summary

- make unlocked `Hey GPT` a persistent OpenClaw-owned voice conversation on the S10+
- keep secure-keyguard speech in a separate persistent zero-tool lane
- use ChatGPT/Codex OAuth subscription access with `openai/gpt-5.6-luna`, never Terra
- add signed, device-bound Android execution with live-presence leases, durable receipts, and phone approval
- enable private phone-spoken contact search, one-shot approved contact calling, and explicit persistent memory without exposing generic node control

## Current Luna Tool Surface

`voice-main` exposes exactly:

- `android_media_play`
- `assistant_contacts_search`
- `assistant_memory_forget`
- `assistant_memory_remember`
- `assistant_phone_call`
- `memory_get`
- `memory_search`
- `messenger_notifications_read`
- `web_fetch`
- `web_search`

Generic nodes, shell/exec, browser control, filesystem access, Gateway administration, messaging groups, and arbitrary Phone Link automation remain denied. The locked agent exposes zero tools. Memory search is pinned to provider `none`, so recall remains local and does not consume embedding API credits.

## Security And Privacy Boundary

The assistant capability broker owns a persistent Ed25519 signing identity, canonical argument hashing, exact node and stable voice-session binding, 60-second proposals, live unlocked-presence leases, durable SQLite plans/receipts, and terminal `UNKNOWN` handling for lost or malformed results.

Contact names and phone numbers never return to Luna, tool content/details, chat history, or the durable ledger. The model supplies only a bounded query and limit. The configured S10+ performs the read, requires a scoped on-phone approval, speaks the result through the active unlocked voice session, and returns only status, match count, truncation, and private-delivery confirmation.

Explicit memory writes only low-sensitivity facts after an explicit user request. It rejects credentials, payment data, security answers, contact records, raw message content, and automatic harvesting. The managed `MEMORY.md` section treats facts as data rather than instructions and is backed by a private per-workspace SQLite ledger.

## Existing Actions And Limits

Spotify exact-track support uses the official App Remote SDK after one-time authorization and verifies matching unpaused playback. `assistant_phone_call` accepts only a contact-name query; the S10+ resolves exactly one recipient locally, shows the real name/number in a secure one-shot approval, and returns only whether the call was placed or the dialer requires a tap. Messenger currently reads bounded active-notification previews only; it does not claim inbox-history access. SMS, calendar, Messenger-history, and selected Windows actions remain roadmap work and will use named signed capabilities rather than generic automation.
